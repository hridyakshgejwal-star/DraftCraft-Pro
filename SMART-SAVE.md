# DraftCraft Pro — Smart Save

Press **Cmd+S** to choose a `.draftcraft` file. Your entire project, including screenplay formatting, character records, Beat Board, outline and hidden story tools, saves together. Later changes save automatically to that file. **Cmd+Shift+S** chooses a new destination and keeps the original file.

A new, edited screenplay asks **Save / Don’t Save / Cancel** when you close or switch projects. Cancel leaves the editor open. Empty, unchanged new screenplays need no prompt. Saved projects save their latest changes before closing. Turning automatic saving off brings back the usual prompt for changed files.

Use **Settings → Files & Autosave** to change timing, save-status visibility and recovery, reveal the current file in Finder or choose another location. Default timing is 1.5 seconds after a pause and 15 seconds during continuous typing.

If a destination is unavailable, your editor stays open and shows **Save Failed**. Reconnect the drive and **Retry**, or **Save As** to a writable location. If closing, choose **Retry / Save As / Cancel Closing**.

After an interruption, **Review Recovery** opens available snapshots. Review shows the screenplay before you restore it. A snapshot that conflicts with a newer saved file opens as a separate unsaved copy. Older unique snapshots are kept until you explicitly discard them. **Don’t Save** discards the active unsaved changes; historical manual backups remain available.

Existing word suggestions, spellcheck, autocomplete, shortcut profiles, page controls, story tools, printing and exports remain available. Story tools stay off by default.
