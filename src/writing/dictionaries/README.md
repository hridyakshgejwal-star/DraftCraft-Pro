# Offline spelling dictionaries

The affix and dictionary files are copied unchanged from `dictionary-en` (US) and `dictionary-en-gb` (UK). Package versions are pinned in the project lockfile. The spelling engine is `nspell`, a Hunspell-compatible implementation. Each license is included here and in the desktop payload.

Upstream: https://github.com/wooorm/nspell and https://github.com/wooorm/dictionaries
