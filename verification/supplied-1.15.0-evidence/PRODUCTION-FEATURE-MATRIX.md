# DraftCraft Pro 1.15.0 — implementation and verification matrix

Baseline: the supplied 1.14.0 Electron/React/TypeScript application. The Rust workspace is preserved and is not the active runtime. “Verified” means the evidence named here, predominantly Linux Chromium and Node checks; it does not imply physical Mac testing or complete Final Draft parity. Partial and blocked capabilities remain explicitly listed.
